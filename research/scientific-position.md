# Scientific Position

## Purpose

This document defines the scientific boundary of the project.

The repository investigates adaptive envelopes as measurable boundary systems in architecture. It does not claim direct equivalence between architectural facades and quantum gravity, black holes, or the SYK model.

## Allowed transfers

The following transfers are conceptually acceptable if explicitly bounded:

- Holographic principle -> boundary-centric representation of interior state
- Phase transition -> discrete or continuous state switching in envelope behavior
- Spin-glass frustration -> analogy for multi-objective design landscapes
- Entropy -> measure of spatial variability, uncertainty, or distributional complexity

## Disallowed claims

- Claiming a facade is a physical holographic surface in the black-hole sense
- Claiming SYK dynamics are materially implemented in a building envelope
- Claiming quantum chaos is directly simulated by Grasshopper geometry workflows
- Claiming consciousness, agency, or biological life in the envelope system

## Research standard

A valid claim in this project should be tied to at least one of four evidence classes:

1. Literature-supported
2. Physically measurable
3. Computationally reproducible
4. Falsifiable by experiment

## Central thesis

The strongest scientific version of this project is not "quantum architecture". It is:

An adaptive architectural envelope can be formalized as an information-processing boundary that transforms environmental and occupancy inputs into controlled geometric or material state changes with measurable performance consequences.
