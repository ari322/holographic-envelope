## T01 — Phase Transition & Adaptive Envelope

```
Act as a theoretical physicist and architectural researcher with expertise in
condensed matter physics and computational design.

Write a 600-word research section arguing that the mathematical formalism of
phase transitions in frustrated quantum magnets (specifically the SYK model
transitioning between quantum chaotic and spin-glass phases) provides a rigorous
analytical framework for designing adaptive building envelopes that undergo
structural-spatial phase transitions in response to environmental variables
(solar radiation intensity, occupancy density, ambient temperature).

Requirements:
- Ground the argument in the Hamiltonian formalism of the SYK model
- Define what constitutes a 'phase' in the architectural context
- Identify the order parameter for the architectural phase transition
- Propose one measurable prediction that would confirm or falsify the analogy
- Write at the level of a Nature-family journal submission
```

## T02 — Holographic Principle and Spatial Boundaries

```
Act as a theoretical architect trained in quantum information theory.

Develop a 500-word theoretical argument for the following claim:
"The Bekenstein-Hawking entropy formula S = A/(4·l_p²) can serve as an
analogy — not a derivation — for a new metric of building envelope intelligence,
where the ratio of boundary information to interior complexity approaches unity
in a maximally adaptive architectural system."

Requirements:
- Clearly distinguish between the physical principle (AdS/CFT) and the architectural analogy
- Define H_boundary and H_interior using Shannon entropy in terms measurable
  from building sensor data (occupancy, temperature, solar radiation)
- Derive the Boundary Information Ratio: BIR(t) = H_boundary(t) / H_interior(t)
- Propose a falsification experiment using real building sensor data
- Acknowledge the limitations of the analogy explicitly
```

## T03 — Spin-Glass Pareto Frustration

```
You are a computational design researcher specialising in multi-objective optimisation
and statistical physics.

Write a research argument (400 words) for the following claim:
"Multi-objective parametric facade optimisation exhibits the formal structure of a
frustrated spin-glass system: no single configuration minimises all objectives
simultaneously, the landscape contains multiple disconnected basins of attraction,
and different optimisation runs with identical settings converge to qualitatively
different design families — equivalent to replica symmetry breaking in spin glasses."

Requirements:
- Define the gene vector σ = [depth, aperture, rotation, hysteresis, maxStep, w_radiation]
- Write the architectural Ising Hamiltonian H_facade(σ)
- Identify the coupling matrix entries J_ij from the conflict structure of the four objectives
- State the frustrated triangle condition for gene triplet (ε, Δs, w_r)
- Propose the Hartigan dip test on pairwise gene distances as the RSB detection protocol
```

## T04 — Bacterial Spore Programming

```
Act as a materials scientist and architectural fabrication researcher.

Write a 400-word technical description of the following novel fabrication concept:
"A building facade panel system where each panel is programmed to a different
maximum deflection angle by varying the number of Bacillus subtilis spore
monolayers deposited on a cork substrate, creating a spatial response gradient
across the facade without any electronics, sensors, or power supply."

Requirements:
- Summarise the known physics of spore hygroscopic actuation (response time, reversibility, lift capacity)
- Explain the layer-to-angle encoding: θ_max(i) = f(n_i)
- Describe the fabrication protocol: spin-coating, drying cycles, parylene sealing
- Connect to Temporal Facade Entropy: explain why a gradient of n_i values produces TFE > 0
- Identify the key unknown: the empirical f(n_i) function for cork substrate
```

## T05 — Full Research Outline (Long Form)

```

headings and 2-sentence summaries of each) for a paper titled:

"Holographic Envelopes: A Spin-Glass Information Framework for Adaptive Architectural Skins"

The paper should cover:
1. The holographic analogy (BIR metric)
2. The Temporal Facade Entropy metric (TFE)
3. The spin-glass / Pareto frustration mapping (H_facade Hamiltonian)
4. Bacterial spore panels as programmable actuators (D03)
5. Grasshopper simulation results and RSB detection (Wallacei protocol)
6. Implications for building performance standards and AI-driven facade control

Write at the level of a submission to Architectural Science Review or
Building and Environment.
```
