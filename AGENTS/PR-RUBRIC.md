# PR rubric

A PR may enter **findings** paths only if:

1. Fills `schemas/idea.yaml` (or links an existing `IS-xxxx`).
2. States `claim_type` honestly (inspiration ≠ validated_result).
3. Names controls and at least one falsification condition.
4. Lists uncertainty / measurement error.
5. Does not move market/NCC into core without downstream gate.
6. For intelligence claims: maps evidence to ≥3 of 5 gate properties.
7. Critic / Evidence Auditor may request changes; Lead may STOP merge of overclaims.

Exploration PRs go under `exploration/` or agent scratch and must say so in the title.
